# Darwinbots Modern offline acceptance on Windows

**Windows acceptance is open.** The November 20–21 cloud review used merged source, the original executable under Linux, and follow-up Linux tests. Every row below requires an observation in an authorized interactive Windows session. Earlier Windows observations cover default creation and Step, legacy settings load and Ctrl+Enter with Load Settings focused, and opening and staging changes in the species editor.

## Prepare the session

1. Use a disposable Windows x64 VM or a dedicated local Windows account. Sign into its desktop and confirm `$env:LOCALAPPDATA` belongs to that account. The package needs the x64 .NET 10 runtime. Close any copies of Darwinbots in the test account.
2. To continue the original walkthrough, download [darwinbots-win-x64, artifact 13329910792](https://github.com/BobertNeek/Darwinbots-Modern/actions/runs/41835933113/artifacts/13329910792) from run 41835933113. Its product revision is `da3581e05903ea5315b8903835519d86a5c7f99d`. For a follow-up build, use that revision's CI `darwinbots-win-x64` ZIP and substitute its SHA-256 below. Record the build revision, artifact ID and hash on each receipt. If the original artifact expires, use a retained ZIP with its recorded hash.
3. From the test account's PowerShell, run the following with the downloaded ZIP path. Keep all file-picker outputs in the printed test directory. The environment variable redirects autosaves, last-start settings and the first-run marker. Death recordings still use the test account's `%LOCALAPPDATA%\Darwinbots Modern\records\DeadRobots.snp`.

   ```powershell
   $zip = 'C:\path\to\darwinbots-win-x64.zip'
   $expected = '38684f367d7feed03763e158b5f1a4d24293e041017474e71847ba197cd964cf'
   if ((Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash -ne $expected) {
       throw 'Windows qualification ZIP hash mismatch'
   }
   $root = Join-Path $env:LOCALAPPDATA ('Darwinbots Acceptance ' + [guid]::NewGuid())
   $package = Join-Path $root 'package'
   $env:DARWINBOTS_AUTOSAVE_DIRECTORY = Join-Path $root 'autosaves'
   Expand-Archive -LiteralPath $zip -DestinationPath $package
   $exe = Get-ChildItem -LiteralPath $package -Recurse -Filter Darwinbots.Desktop.exe
   if (@($exe).Count -ne 1) { throw 'Expected one packaged executable' }
   Write-Host "Test directory: $root"
   Start-Process -FilePath $exe.FullName -WorkingDirectory $exe.DirectoryName
   ```

4. In New Simulation, use CPU and a small field with capacity 64 and three copies each of a bundled animal and vegetable. Start and Pause. Use the toolbar Save button to write a baseline `baseline.db3s` and preserve it. Reload it between independent checks. Use a copy of [the pinned original simulation fixture](../engine/tests/fixtures/db24832-original-user.sim) for native import. Keep fixture input files separate from exports.

PowerShell 7 can read the F2 seed summary or the full state for the founder, poison, and skin checks. Use a Modern checkpoint written by the toolbar Save button.

```powershell
function Read-Db3sCheckpoint($path, [switch]$Raw) {
    $bytes = [IO.File]::ReadAllBytes((Resolve-Path -LiteralPath $path).Path)
    if ($bytes.Length -lt 10 -or [Text.Encoding]::ASCII.GetString($bytes, 0, 4) -ne 'DB3S') {
        throw 'Expected a DB3S checkpoint'
    }
    $json = [Text.Encoding]::UTF8.GetString($bytes, 10, $bytes.Length - 10)
    $world = $json | ConvertFrom-Json
    if ($Raw) { return $world }
    [pscustomobject]@{
        Cycle = $world.native_cycle
        Population = @($world.slots | Where-Object { $null -ne $_.organism }).Count
        Seed = $world.config.seed
        RandomState = $world.native_random.state
    }
}

Read-Db3sCheckpoint (Join-Path $root 'native-f2-cancel.db3s')
```

## Prepare the Robot Info mutation fixture

Run this in the disposable Windows profile after saving the two-robot checkpoint in the Reproduce check. It makes a new DB3S containing five test entries on the first robot and leaves the second empty.

```powershell
$source = Join-Path $root 'robot-info-reproduction.db3s'
$fixture = Join-Path $root 'robot-info-mutations.db3s'
[byte[]]$bytes = [IO.File]::ReadAllBytes($source)
if ($bytes.Length -lt 10 -or [Text.Encoding]::ASCII.GetString($bytes, 0, 4) -ne 'DB3S') {
    throw 'Expected the Robot Info reproduction checkpoint'
}
$text = [Text.Encoding]::UTF8.GetString($bytes, 10, $bytes.Length - 10)
$pattern = [regex]::new('"detailed_log":\[\]')
if ($pattern.Matches($text).Count -ne 2) { throw 'Expected two empty mutation logs' }
$entries = @(1..5 | ForEach-Object { "Acceptance mutation $_" }) | ConvertTo-Json -Compress
$payload = [Text.Encoding]::UTF8.GetBytes($pattern.Replace($text, '"detailed_log":' + $entries, 1))
$length = [BitConverter]::GetBytes([uint32]$payload.Length)
[IO.File]::WriteAllBytes($fixture, [byte[]]($bytes[0..5] + $length + $payload))
```
